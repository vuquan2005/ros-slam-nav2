# Các package của robot vi sai

- `dif_description`: mô hình robot và cấu hình RViz.
- `dif_gazebo`: phòng mô phỏng và bridge ROS–Gazebo.
- `dif_bringup`: khởi chạy xem mô hình hoặc mô phỏng.

Dùng plugin DiffDrive có sẵn của Gazebo. Chưa cần package động học riêng trong giai đoạn mô phỏng ban đầu. Hướng dẫn build và chạy ở [README workspace](../README.md).
